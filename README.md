# sql-hospital-analysis
# 🏥 Hospital SQL Analysis

### 📊 Exploring Hospital Data with MySQL

A SQL-based data analysis project focused on understanding **patients, doctors, departments, hospital stays, medical expenses, and locations** through practical SQL queries.

---

## 📌 Project Overview

This project uses SQL to analyze hospital data and answer **10 business-style questions**.

The analysis focuses on:

* 👥 Patient volumes
* 👨‍⚕️ Doctor availability
* 🏥 Department performance
* 💰 Medical expenses
* 📅 Hospital stay duration
* 📍 City-wise patient distribution
* 📈 Monthly medical expense trends

---

## 🔍 Analysis Covered

| #  | Analysis                                                 |
| -- | -------------------------------------------------------- |
| 01 | 👥 Total Number of Patients                              |
| 02 | 👨‍⚕️ Average Number of Doctors per Hospital             |
| 03 | 🏥 Top 3 Departments with the Highest Number of Patients |
| 04 | 💰 Hospital with the Maximum Medical Expenses            |
| 05 | 📊 Daily Average Medical Expenses                        |
| 06 | ⏱️ Longest Hospital Stay                                 |
| 07 | 📍 Total Patients Treated Per City                       |
| 08 | 🏥 Average Length of Stay Per Department                 |
| 09 | 📉 Department with the Lowest Number of Patients         |
| 10 | 📅 Monthly Medical Expenses Report                       |

## 🧠 SQL Concepts Practiced

This project demonstrates practical use of:

```text
SELECT
GROUP BY
ORDER BY
HAVING
SUM()
AVG()
ROUND()
LIMIT
DATEDIFF()
STR_TO_DATE()
DATE_FORMAT()
```

## These queries are used to aggregate hospital data, compare departments and hospitals, calculate stay durations, and generate monthly reports.

## 🎯 Project Objective

The goal of this project is to strengthen practical SQL skills by working with a hospital dataset and converting raw data into meaningful analytical results.
